# 0.1.3 延迟与语境验证

使用本机 Codex 0.153.4 的 ChatGPT 订阅、gpt-5.6-luna、none 推理，运行 `node scripts/benchmark.mjs`。以下是一次实际测量，不是性能保证。

| 输入场景 | 首条解释 | 整段完成 | 语境检查 |
| --- | ---: | ---: | --- |
| 房间贵，但景色 sick | 5.79 秒 | 6.93 秒 | 通过 |
| 吃坏海鲜后 feel sick | 4.19 秒 | 4.30 秒 | 通过 |
| 火车可能晚点，晚饭 play it by ear | 4.40 秒 | 5.47 秒 | 通过 |
| 询问导游八卦 spill the tea | 3.37 秒 | 3.49 秒 | 通过 |

首条耗时从调用开始计算，包含本地连接准备；第二至第四次复用同一进程。测试未命中插件缓存。检查同时核对对应表达和中文语境含义；不是仅检查 JSON 格式。

`npm test` 的 19 项测试通过，包括滚动字幕扩写、积压保留、部分结果转发、完成后缓存、取消、额度错误和字幕预读不会阻塞当前字幕分析。

尚待验证：浏览器重载 0.1.3 后，真实 YouTube 字幕出现到卡片显示的耗时。上表不能代替这项验证；字幕等待、排队和等级筛选会影响实际体验。
